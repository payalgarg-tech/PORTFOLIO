# Payal Garg Portfolio

A modern, responsive personal portfolio website for Payal Garg, built using HTML, CSS, and JavaScript. The site highlights her skills, education, experience, projects, and contact details in a clean and professional layout.

## Overview

This portfolio is designed to present a frontend developer profile with:

- A modern hero section with animated text
- Dark and light theme toggle
- Mobile-friendly responsive navigation
- Skills, experience, and education sections
- Project filtering cards
- Contact and resume access buttons
- Clean glassmorphism-inspired UI design

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts

## Project Structure

```bash
Payal-Portfolio/
│
├── index.html

├── css/

├── js/

```

## Features

- Fully responsive layout for desktop, tablet, and mobile
- Interactive navigation with smooth scrolling
- Typewriter effect in the hero section
- Theme switching with saved preference
- Project category filtering
- Professional landing page for personal branding

## Run Locally

You can open the project directly in a browser, or run a local server:

```bash
cd Payal-Portfolio
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```
